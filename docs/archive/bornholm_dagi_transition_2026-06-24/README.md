# Bornholm DAGI Transition Archive - 2026-06-24

This folder contains Bornholm transition handoffs from the move to the DAGI
Landsdel landmask and R9 QA package.

These files are preserved as audit trail, but they are no longer active steering
documents. Several notes describe work that has since been completed or
superseded, including the coastal QGIS review and later strand-protection app
behavior fixes.

Current Bornholm steering lives in:

- `regions/bornholm/region.json`
- `regions/bornholm/REGIONAL_NOTES.md`
- `docs/ACTIVE_PROJECT_DOCUMENTS_2026-06-24.md`

The original Bornholm V1-to-V2 export handoff remains in root `docs/` because
`regions/bornholm/region.json` still references it as source-package provenance.
